Getting Started

Up and running in minutes

01

Add PhineX to your server

Click "Add to Discord", pick your server and authorize. You're sent straight back to the dashboard once the bot has joined.

02

Open the Dashboard

Log in with Discord, pick a server (or add the bot to one) and configure every feature from the settings panels.

03

You're live

Changes apply instantly. Post your ticket panels from the dashboard, or run /ticket setup in Discord.
